01 / SENSOR DATA

Sensor log checker.

Spot missing readings, low confidence and unusual ranges in a simple robot sensor log. Paste a CSV or load a file. Processing happens in your browser.

HOW IT WORKS

Readings, made visible.

Expected columns: timestamp_ms, range_mm, confidence. The preloaded sample is illustrative and does not contain MARIO data.

  • Missing or invalid range, confidence or timestamp
  • Confidence below 0.5
  • Range outliers using median absolute deviation, with a 5 mm minimum threshold

This is a demonstration for simple CSV logs. Review flagged readings against sensor context before making engineering decisions.
