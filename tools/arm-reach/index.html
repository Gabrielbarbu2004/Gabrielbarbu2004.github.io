Two-link arm planner.

Set a target and link lengths to check whether a simple planar arm can reach it. See both elbow configurations.

PLANAR INVERSE KINEMATICS

Reach is geometry.

A two-link arm can reach targets between |L₁ − L₂| and L₁ + L₂ from its base. For a reachable target, the law of cosines gives two joint configurations with positive and negative elbow bend.

  • Enter link lengths in metres
  • Set target X and Y relative to the base
  • Compare both joint-angle solutions on the plot

This is a 2D teaching model. The on-orbit servicing concept used six-degree-of-freedom arms, so its full kinematics and joint limits are more involved. The plot does not check obstacles or collisions.
